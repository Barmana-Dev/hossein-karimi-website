# وب‌سایت شخصی دکتر حسین کریمی

پایگاه حرفه‌ای معرفی شخصیت، سوابق، تخصص‌ها و راه‌های ارتباط دکتر حسین کریمی در حوزه حقوق، امور گمرکی و تجارت.

## 📋 پیش‌نیازها

قبل از اجرای پروژه، مطمئن شوید که موارد زیر روی سیستم شما نصب هستند:

- **Node.js** (نسخه ۱۸ یا بالاتر)
- **Docker** (برای اجرای دیتابیس PostgreSQL)
- **Git** (برای کلون کردن پروژه)

## 🚀 راه‌اندازی و اجرا

### ۱. کلون کردن پروژه

```bash
git clone <repository-url>
cd hossein-karimi-website
```
