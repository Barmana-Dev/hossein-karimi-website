# محتوای موردنیاز پیش از انتشار (Content Needed)

داده‌های موجود در دیتابیس با اجرای `seed` ساخته می‌شوند و **همه به‌صورت پیش‌نویس (draft)**
هستند. API عمومی فقط محتوای `published` را برمی‌گرداند؛ بنابراین پس از seed، فهرست‌های
سایت (سوابق، مقالات، کارگزاری‌ها، حوزه‌ها) خالی دیده می‌شوند. این رفتار عمدی است:
هیچ محتوای آزمایشی بدون تأیید صاحب سایت منتشر نمی‌شود.

برای انتشار، هر مورد را در پنل مدیریت وارد/تأیید کنید و سپس وضعیت آن را به
«منتشر شده» تغییر دهید.

## ۱. اطلاعات هویتی و برند

- [ ] عنوان حرفه‌ای دقیق (وکیل پایه یک، مشاور گمرکی، دکتری و …)
- [ ] زیرعنوان سایت (شعار کوتاه)
- [ ] بیوگرافی کوتاه (حدود ۲ تا ۳ خط)
- [ ] بیوگرافی کامل صفحه «درباره من»
- [ ] عکس پرتره رسمی با کیفیت بالا
- [ ] فایل لوگو در صورت وجود نسخه رسمی

## ۲. سوابق حرفه‌ای

- [ ] فهرست دقیق سوابق با نام سازمان، سمت و بازه زمانی
- [ ] توضیح هر سابقه (حداقل دو تا سه خط)
- [ ] دسته‌بندی هر سابقه (حقوقی، گمرکی، مدیریتی، آموزشی، کسب‌وکار)
- [ ] منبع یا لینک رسمی برای هر سابقه (اختیاری)

## ۳. حوزه‌های تخصصی

- [ ] عنوان و خلاصه هر حوزه
- [ ] متن کامل هر حوزه
- [ ] انتخاب آیکون مناسب برای هر حوزه

## ۴. شبکه کارگزاری‌ها

- [ ] نام رسمی هر مجموعه
- [ ] نوع ارتباط واقعی (مشاور، همکار، شریک)
- [ ] حوزه فعالیت و شهر
- [ ] آدرس وب‌سایت رسمی (در صورت وجود)
- [ ] تصویر/لوگوی هر مجموعه (اختیاری)

## ۵. مقالات و تحلیل‌ها

- [ ] عنوان، خلاصه و متن کامل هر مقاله
- [ ] تصویر شاخص برای هر مقاله
- [ ] دسته‌بندی و زمان مطالعه
- [ ] تاریخ انتشار

## ۶. رسانه و رویدادها

- [ ] فهرست مصاحبه‌ها، سخنرانی‌ها و رویدادها
- [ ] تاریخ هر رویداد و لینک منبع

## ۷. اطلاعات تماس و صفحات حقوقی

- [ ] شماره تماس رسمی
- [ ] ایمیل رسمی
- [ ] آدرس دقیق دفتر
- [ ] متن نهایی «حریم خصوصی»
- [ ] متن نهایی «قوانین و مقررات»
- [ ] متن صفحه «تماس»

## ۸. فنی

- [ ] مقدار `NEXT_PUBLIC_SITE_URL` روی دامنه نهایی
- [ ] مقدار `NEXT_PUBLIC_API_URL` روی دامنه API نهایی
- [ ] مقدار `CORS_ORIGINS` روی دامنه فرانت‌اند
- [ ] رمزهای `SEED_*_PASSWORD` پیش از اجرای seed
